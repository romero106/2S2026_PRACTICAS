## Acerca de este repositorio

Este repositorio contiene actividades, prácticas y proyectos desarrollados durante el curso **Prácticas Iniciales**.

Su propósito es reunir y organizar de forma estructurada los trabajos realizados durante el semestre, permitiendo localizar fácilmente cada actividad.

---

## Estructura del repositorio

El repositorio está organizado en distintos directorios según el propósito de cada archivo. La estructura general es la siguiente:

```text
/
├── Charla-1/
│   ├── README.md
│   └── src/
│       ├── Algoritmo.java
│       ├── Estudiante.java
│       └── Main.java
│
├── Charla-2/
│   ├── README.md
│   └── src/
│       ├── Persona.java
│       ├── Estudiante.java
│       ├── Profesor.java
│       └── Main.java
│
├── Charla-3/
│   └── README.md
│
└── README.md
```

Cada directorio contiene los archivos correspondientes a las actividades desarrolladas durante el curso.

## Actividades

Aquí se registran las principales actividades desarrolladas durante el curso, así como su estado de avance.

|  No.  | Actividad                     | Tema                                                                                                                                                                                                                              | Estado |
| :---: | :---------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----: |
|  01   | [Primera charla](./Charla-1/) | Introduce la relación entre problema, algoritmo y código, y utiliza ese punto de partida para presentar los conceptos básicos de la Programación Orientada a Objetos: clases, atributos, métodos y objetos.                       |   ✅    |
|  02   | [Segunda charla](./Charla-2/) | Continúa la introducción a POO mediante **constructores, encapsulamiento, herencia, polimorfismo y abstracción**, utilizando un mismo conjunto de clases para conectar los conceptos.                                             |   ✅    |
|  03   | [Tercera charla](./Charla-3/) | Presenta de forma intuitiva la diferencia entre **reglas explícitas y aprendizaje a partir de datos**, para luego introducir modelos, predicciones, modelos de lenguaje, tokens, contexto, alucinaciones y uso responsable de IA. |   ✅    |
